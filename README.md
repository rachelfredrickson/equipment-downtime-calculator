# Equipment Downtime & Cost Loss Calculator

A clean, professional, and easy-to-use web-based calculator for estimating the financial impact of equipment downtime.

Built specifically for maintenance teams, plant managers, and operations professionals who need quick and accurate downtime cost estimates.

## Features

- Calculates **Total Downtime Hours**
- Breaks down **Revenue Loss**, **Variable Costs**, and **Fixed Repair Costs**
- Clean, modern light-themed design with your brand color (#C8102E)
- Fully responsive – works great on desktop, tablet, and mobile
- Real-time updates as you change inputs
- Press **Enter** to calculate instantly
- No installation required – just open the HTML file in any browser
- Works completely offline

## How to Use

1. Save the file `downtime-calculator.html` to your computer.
2. Double-click the file to open it in your web browser (Chrome, Edge, Firefox, etc.).
3. Enter your equipment data:
   - Number of downtime incidents (per year/month/quarter)
   - Average hours per downtime incident
   - Revenue generated per operating hour
   - Additional costs per hour of downtime
   - Fixed repair cost per incident
4. Click **"Calculate Total Loss →"** or simply press **Enter**.
5. View the detailed breakdown and total estimated financial impact.

## Customization Tips

- Change the default values in the form to match your typical equipment data.
- Duplicate the HTML file and create one version for each critical piece of equipment.
- You can easily modify the accent color by editing the `#C8102E` value in the `<style>` section.
- Print the page or take a screenshot for reports and meetings.

## Inputs Explained

| Input                        | Description |
|-----------------------------|-----------|
| **Number of downtime incidents** | How many times the equipment fails in your chosen period |
| **Average downtime per incident (hours)** | Mean Time To Repair (MTTR) |
| **Revenue per operating hour ($)** | Lost revenue when the machine is not running |
| **Additional costs per downtime hour ($)** | Labor, utilities, penalties, idle staff, etc. |
| **Fixed repair cost per incident ($)** | Parts, service calls, emergency repairs |

## Example

With the default values:
- 12 incidents per year
- 6.5 hours average downtime each
- $1,250 revenue per operating hour
- $320 additional costs per hour
- $850 fixed repair cost per incident

→ **Estimated annual loss: ~$127,000**
